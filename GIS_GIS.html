Project Graffiti IntelliSense (GIS)

GIS & Web Development.

Brief

Year: 2024
Location: Montreal/Toronto/Vancover, Canada
Client: Fanshawe College
Tool: SQL, C#, .NET, HTML, CSS, Javascript, Google API

Background

Graffiti serves as both an artistic expression and a cultural marker in urban spaces. However, mapping and analyzing graffiti trends require integrating diverse data sources, including open datasets, geospatial information, and interactive visualization tools.

Introduction

Using SQL for data management and C# .NET, HTML, JavaScript, and Google API for web development, I created Project Graffiti IntelliSense—an interactive website that processes and visualizes open data related to graffiti in Canadian cities. This project not only showcases graffiti culture but also provides insights into spatial distribution patterns and urban artistic trends.

Key Contributions:

o Processed and stored open data using SQL for efficient data management.

o Developed a C# .NET-based interactive website integrated with Google API and JavaScript web maps.

o Enabled dynamic visualization of graffiti locations, fostering cultural awareness and urban engagement.
